# Lung Cancer Prediction Web App 🫁

A Machine Learning–powered web application that predicts the likelihood of lung cancer based on patient symptoms and lifestyle factors.

## 🚀 Features
- KNN Machine Learning Model
- Hyperparameter Optimization
- Flask Web Framework
- User-friendly UI (HTML + CSS)
- Model Serialization using Joblib
- Deployable on Render

## 🧠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Flask
- HTML, CSS
- Joblib
